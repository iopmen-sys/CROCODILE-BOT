# CROCODILE BOT 🐊

Стартовая версия Telegram-бота на Python + Aiogram 3.

## Что уже есть
- Регистрация при `/start`
- Главное меню
- Профиль и баланс CROCODILE
- Бесплатная игра `/roll` с небольшой игровой наградой
- Лидерборд
- Разделы «Финансы», «Подарки», «Настройки» (пока информационные)
- SQLite для хранения пользователей

> CROCODILE в этой версии — только внутренняя игровая валюта без денежной стоимости. Реальные платежи и вывод не подключены.

## Запуск локально
1. Установи Python 3.10 или новее.
2. Открой терминал в папке проекта.
3. Выполни `pip install -r requirements.txt`.
4. Скопируй `.env.example` в `.env`.
5. В `.env` вставь токен Telegram-бота в `BOT_TOKEN`.
6. Запусти `python main.py`.

## GitHub
1. Создай новый пустой репозиторий.
2. Загрузи в него `main.py`, `requirements.txt`, `.env.example`, `.gitignore`, `README.md`.
3. Не загружай `.env` и не публикуй токен бота.
4. Для запуска на сервере позже добавим инструкции под выбранный хостинг.
